# Docs New

This directory is the new source of truth for product, engineering, and data documentation.

## Structure

- `product/` describes the product scope, feature behavior, and screen-level flows.
- `engineering/` defines the backend architecture, code organization, and implementation rules.
- `data/` describes database structure and migration strategy.

## Recommended Reading Order

1. `product/PROJECT_OVERVIEW.md`
2. `product/FEATURE_OVERVIEW.md`
3. `engineering/ARCHITECTURE_OVERVIEW.md`
4. `engineering/FOLDER_STRUCTURE.md`
5. `engineering/MODULE_BOUNDARIES.md`
6. `engineering/ROUTING_AND_MERCHANT_CONTEXT.md`
7. `engineering/ERROR_HANDLING.md`
8. `engineering/DB_ACCESS.md`
9. `data/DATABASE_SCHEMA.md`

## Migration Strategy

The legacy `docs/` directory remains untouched during the transition.
New or revised guidance should be written in `docs-new/`.
